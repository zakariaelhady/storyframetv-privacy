Privacy Policy

Last updated: October 2026

This application ("StoryFrameTV automation tool") is a personal-use tool operated by a single individual developer for the sole purpose of automatically generating and publishing video content to a personal YouTube channel and Facebook Page.

Who uses this application

This application has exactly one user: its developer and operator. It is not distributed, offered, or made available to the public or to any third party.

What data this application accesses

This application uses the YouTube Data API and the Facebook Graph API solely to upload video content to accounts owned and controlled by the developer. It does not access, collect, store, or share any data belonging to any other person or YouTube/Facebook user.

Data storage

This application stores only the content it generates (story scripts, images, audio, and video files) and operational metadata (upload status, timestamps) in a private database controlled by the developer. No personal data of any third party is collected or stored.

Data sharing

This application does not share, sell, or transmit any data to any third party other than the AI service providers (for text, image, and voice generation) and video platforms (YouTube, Facebook) strictly necessary to produce and publish its content.
